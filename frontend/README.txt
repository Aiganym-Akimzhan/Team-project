KINO — фильм сайты

Файлдар:
  index.html  — сайттың беті (стильдер әр элементтің өзінде жазылған, style="...")
  index.js    — логика (фильмдер, таңдаулылар, видео, тіркелу)
  data.json   — фильмдер деректері (атауы, рейтинг, сипаттама, сурет, видео)
  posters/    — фильм суреттері
  videos/     — видеолар

Қалай ашу керек:
  VS Code -> "Live Server" кеңейтімін орнатыңыз -> index.html оң жақ батырма -> "Open with Live Server".
  (index.html-ді екі рет басып ашсаңыз, data.json оқылмайды.)
